APEXVIGIL PLATFORM SPECIFICATIONS

ApexVigil Platform Technical Documentation

System Architecture, Technology Stack & Engineering Blueprint for Autonomous IPsec Protocol Intelligence
EXECUTIVE PLATFORM CONTEXT: Virtual Private Networks (VPNs) built on IPsec represent the backbone of secure inter-site, cloud, and military communications. However, security hinges entirely on robust cryptographic cipher suites, ephemeral key exchange, strict replay windows, and proper configuration hygiene. Traditional packet analyzers produce raw dumps requiring scarce expert interpretation. ApexVigil introduces an autonomous, AI-driven protocol inspection platform that analyzes live network streams and PCAP traces, infers VPN operating modes, evaluates cryptographic strength, classifies encrypted payload categories via machine learning, and synthesizes hardened executive and technical reports via local Ollama models.

Core Platform Capabilities & Design Principles

Architectural guarantees separating statistical inference from strict cryptographic rules
PILLAR 1 ZERO-HALLUCINATION
Strict JSON Data Contract Separation
The generative reasoning model (Ollama) is entirely decoupled from layout, typography, dimensions, and styling. The model only populates validated JSON schema fields. Deterministic analyzers own facts; JavaScript owns clipping and SVG vector rendering; CSS locks A4 boundaries.
PILLAR 2 DEEP CRYPTANALYSIS
Deterministic Security Scoring & Weightage
Evaluates IPsec transforms against rigorous standards (NIST SP 800-77 Rev 1, CIS IPsec Benchmark). Scores are apportioned across 5 weighted domains with penalty tracking, pinpointing exact configuration defects and root causes.
PILLAR 3 METADATA INFERENCE
Encrypted Traffic Classification Without Decryption
Utilizes deep statistical feature extraction (packet inter-arrival times, burst distributions, payload entropy) to accurately classify application traffic (VoIP, WhatsApp, Video, Bulk) concealed inside opaque ESP envelopes.
PILLAR 4 MULTI-TIER REPORTING
Automated 4-Tier Document Suite
Simultaneously publishes four targeted deliverables: Executive Report (C-suite risk posture), Technical Report (packet timeline & characteristics), Security Assessment (weighted rubric & CLI playbook), and Technical Documentation.

Complete Technology Stack & Subsystem Specifications

Comprehensive blueprints of testbed infrastructure, network parsing libraries, AI models, and presentation layers

Subsystem Technology Matrix

Enterprise tooling and libraries powering the ApexVigil pipeline
LAYER 01: TESTBED INFRASTRUCTURE LINUX KERNEL
VPN Testbed & Cryptographic Gateway
StrongSwan 5.9.13 · Linux ip-xfrm · OpenSSL 3.0 · Network Namespaces
Laboratory testbed capable of provisioning synthetic IPsec tunnels across isolated network namespaces. Supports automated permutations: Tunnel vs Transport modes, IKEv1/IKEv2, AES-CBC vs AES-GCM, DH Groups 14–21, PFS toggling, and IPv4/IPv6 communication channels.
LAYER 02: TRAFFIC INGESTION NETWORK I/O
High-Throughput Packet Capture & Ingestion
Wireshark / TShark 4.2 · TCPDump · Libpcap · AF_PACKET / eBPF
Captures wire-speed traffic across interfaces (virtual, Ethernet, overlay networks like Tailscale). Filters and extracts IKE negotiations (UDP 500), NAT-Traversal tunnels (UDP 4500), raw ESP packets (IP protocol 50), and optional AH headers without packet drop.
LAYER 03: PROTOCOL DISSECTION PARSER CORE
Deep IPsec Protocol Dissector & State Engine
Scapy 2.5 · PyShark · Custom C/Python IPsec Dissector
Decodes IKE Security Associations, transforms, cryptographic proposals, Diffie-Hellman public values, and nonces. Dissects ESP envelopes to extract Security Parameter Index (SPI), Sequence Numbers, NAT-T encapsulations, and padding patterns.
LAYER 04: AI / ML INFERENCE DEEP LEARNING
Encrypted Traffic Classification & Anomaly Engine
PyTorch 2.2 · Scikit-Learn · 1D-CNN · Random Forest · Isolation Forest
Employs a hybrid 1D-CNN + Random Forest classifier to identify application types concealed inside encrypted ESP envelopes (VoIP, WhatsApp, Video, Bulk, Web). An Isolation Forest identifies traffic bursts, exfiltration spikes, and replay injection anomalies.
LAYER 05: REASONING CORE LOCAL LLM
Generative AI Reasoning Layer
Ollama Local Runtime · Llama-3-8B-Instruct / Mistral-7B · Pydantic
Executes locally on analyst workstations with zero external cloud telemetry. Prompted with deterministic parser evidence and constrained via strict JSON Schema. Synthesizes executive summaries, threat analyses, and actionable remediation instructions.
LAYER 06: PRESENTATION REPORT PUBLISHER
Deterministic Vector Report Publisher
HTML5 · Vanilla CSS3 (Strict A4) · Native JavaScript · Headless Chromium
Provides zero-overflow, pixel-perfect publishing. Dynamic SVG charts are generated programmatically by JavaScript from live JSON telemetry. Output complies strictly with corporate typography, color tokens, and A4 print standards.

Pipeline Execution, Data Contracts & CLI Manual

The ApexVigil Zero-Overflow Ollama Contract

Guarantees deterministic presentation while leveraging generative reasoning
DATA CONTRACT ARCHITECTURE: Local language models often induce UI breakage through unbounded token generation, inconsistent HTML/CSS formatting, and hallucinated network properties. ApexVigil resolves this by enforcing a strict tripartite contract:
1. Deterministic Analyzer: Extracts protocol facts, SPIs, cryptographic transforms, and statistics into structured JSON.
2. Local Ollama Worker: Receives structured facts and fills only constrained string values (Executive summary ≤ 55 words, AI recommendations ≤ 2 items). Ollama outputs pure JSON matching the report schema.
3. Fixed Vector Renderer: The template owns 100% of styles, box dimensions, typography, and SVG charts. JavaScript clips strings to hard character ceilings, making box overflow mathematically impossible.

Command-Line Execution & Pipeline Orchestration

Automated end-to-end execution workflow
# APEXVIGIL END-TO-END PIPELINE CLI
# 1. Ingest PCAP, parse IPsec state, and classify encrypted traffic:
$ python3 analyze_ipsec.py --pcap traces/sih26-asim-golden.pcap --out telemetry.json

# 2. Execute deterministic security rule audit and compute domain weightages:
$ python3 audit_security.py --telemetry telemetry.json --profile enterprise-nist --out audit.json

# 3. Trigger local Ollama to populate JSON data contracts:
$ python3 synthesize_reports.py --model llama3:8b --audit audit.json --generate-all-reports

# 4. Compile vector HTML templates to print-perfect A4 PDF:
$ node render_pdf.js --all --print-background --out /var/reports/
