# ApexVigil Autonomous Protocol Intelligence Report Suite

This suite contains the **4 standardized A4 print-ready reports and engineering documentation** for the ApexVigil AI-driven IPsec protocol analysis and security assessment platform.

All dynamic reports are designed under a strict **tripartite architecture**:
Local Ollama produces **validated JSON data values only**. It must **never** output HTML, CSS, SVG, dimensions, fonts, colors, or layout directives. The template owns presentation, layout boundaries, clipping, and dynamic SVG vector charting.

---

| Deliverable | Primary File | Stylesheet | Script / Data Contract | Purpose & Focus |

Security Assessment Report** | `security_assessment_report.html` | `security_assessment_report.css` | `security_assessment_report.js` | Quantitative audit scoring, domain weightages (Crypto 30%, PFS 25%, Auth 20%, Replay 15%, Anomaly 10%), penalty deduction analysis, dynamic SVG domain comparison chart, and cybersec remediation playbook (`swanctl`, `ip xfrm`). |
| **4. Technical Documentation** | `technical_documentation.html` | `technical_documentation.css` | *Static Whitepaper* | Architectural blueprint, technology stack specifications (StrongSwan, Wireshark, Scapy, PyTorch, Ollama), testbed permutation matrix, and CLI execution manual. |

## Dynamic Vector Graphics (SVGs)
All charts are real vector SVGs rendered dynamically via JavaScript rather than static images:
- **Technical Report**: Packet rate timeline SVG with anomaly markers dynamically rendered from `REPORT.timeline.points`.
- **Executive Report**: Composite threat velocity and risk trendline SVG rendered dynamically from `EXECUTIVE_REPORT.trend.points`.
- **Security Assessment Report**: Domain benchmark variance comparison chart (Target Baseline vs. Observed Score across 5 domains) rendered dynamically from `ASSESSMENT_REPORT.chartData`.

To update the graphs dynamically in code or via Ollama, modify the corresponding JSON points arrays.

---

## Hard Content & Zero-Overflow Safeguards
All templates enforce strict layout safety:
1. Containers have fixed millimeter heights and `overflow: hidden`.
2. Text strings are automatically clipped with ellipsis (`…`) by JavaScript utility functions (`clip(str, maxLen)`).
3. Summaries are constrained to maximum word counts (`words(str, maxWords)`).
4. No dynamic text generated by local Ollama can expand the page boundaries or cause page bleed on A4 print.

## Ollama JSON Contracts & System Prompts

### Technical Report Prompt (`REPORT`)
```
You are ApexVigil's local security intelligence language model. Return pure JSON matching the REPORT schema. Never output markdown, HTML, CSS, or styling attributes. Keep executive summary to 50 words maximum. Keep recommendations concise and evidence-grounded.
```

### Executive Report Prompt (`EXECUTIVE_REPORT`)
```
You are ApexVigil's executive risk briefing language model. Return pure JSON matching the EXECUTIVE_REPORT schema. Focus on strategic business impact, compliance gaps, and clear answers to whether immediate action is required. Maximum summary length: 55 words.
```

### Security Assessment Report Prompt (`ASSESSMENT_REPORT`)
```
You are ApexVigil's cybersecurity audit language model. Return pure JSON matching the ASSESSMENT_REPORT schema. Explain why specific score penalties were deducted, detail the threat scenarios, and provide concrete engineering remediation directives.
```

## Exporting to PDF
Open any of the `.html` files in Chromium or Google Chrome:
1. Press `Ctrl + P` (Print).
2. Set **Destination** to `Save as PDF`.
3. Set **Paper size** to `A4`.
4. Set **Margins** to `None` (or `Default`).
5. **Enable** `Background graphics`.
6. Click **Save**.
